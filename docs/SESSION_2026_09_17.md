## Errors hit and how we fixed them

### 1. `WARNING: Skipping segment-anything-hq as it is not installed`
Not an error — pip just said the stale PyPI package wasn't there to uninstall.  
The real issue was the kernel hadn't been restarted after the install.  
**Fix:** restart kernel after `pip install git+https://github.com/SysCV/sam-hq.git`, then re-run install cell.

### 2. `ModuleNotFoundError: No module named 'monai'`
`train_hq.py` was importing `monai.losses.DiceLoss`. MONAI isn't pre-installed on Kaggle.  
**Fix:** replaced with a native PyTorch `SoftDiceLoss` class — same formula, zero extra dependencies.

### 3. `RuntimeError` — `CombinedDentalLoss` had no `forward()` method
The class was defined with `__init__` only. `criterion(probs, masks)` crashed because `nn.Module.__call__` dispatched to a missing `forward()`.  
**Fix:** wrote the missing `forward(pred_logits, gt_masks)` method.

### 4. `RuntimeError: mask_tensor dtype is Long` (MONAI DiceLoss)
Masks were created with `.long()` (int64) but loss functions require float.  
**Fix:** changed `mask_tensor = ... .long()` → `.float()` in `ToothDatasetHQ.__getitem__`.

### 5. `RuntimeError: BCELoss is unsafe to autocast`
`nn.BCELoss` is explicitly blocked by PyTorch inside `torch.amp.autocast` when inputs are float16 probabilities.  
**Fix:** replaced with `nn.BCEWithLogitsLoss` and changed the training loop to pass raw logits (`upsampled`) to the criterion instead of `probs`. The criterion now applies sigmoid internally.

### 6. Same autocast crash in `BoundaryLoss`
`BoundaryLoss.forward()` also called `F.binary_cross_entropy(pred_probs, ...)` — same block.  
**Fix:** switched to `F.binary_cross_entropy_with_logits(pred_logits, ...)`. `BoundaryLoss` now accepts logits, not probabilities.

### 7. `pipeline.py` — wrong bbox function alias (latent bug, would crash on run)
`get_bbox_prompt_yolo` was imported as `get_bbox_prompt`, but `pipeline.py` called it with only `image_shape` — missing the required `yolo_model` arg.  
**Fix:** aliased `get_bbox_prompt` (the generic centre-crop version) instead. `pipeline.py` doesn't load a YOLO model, so using the generic box is correct here.

### 8. `validate()` threshold was 0.9 instead of 0.5 (silent bug)
Training-time DSC used `probs > 0.9` to threshold predictions. This deflates training DSC scores and causes the best-checkpoint selection to misfire.  
**Fix:** changed to `probs > 0.5` in `validate()`. Inference in `infer_hq.py` still uses `MASK_THRESHOLD=0.9` to reduce gum bleed — that's intentional and separate.

## Training Run Results (20/20 Epochs Completed)

- **Total Run Time**: ~5,348 seconds (~89 minutes) on Kaggle T4 GPU
- **Final Epoch 20 Loss**: `0.2196` (down from `0.3212` in Epoch 1)
- **Best Validation DSC**: **`0.8628`**
- **Saved Checkpoint**: `/kaggle/working/checkpoints/medsam_hq_tooth_best.pth`

### Performance Analysis
- **Why DSC plateaued around 0.86**:
  1. Only the HQ Mask Decoder was fine-tuned; the heavy MedSAM image encoder remained completely frozen.
  2. Fixed learning rate without a scheduler caused validation DSC to fluctuate between 0.844 and 0.863 in later epochs.
### Visual Evaluation of Outputs (`docs/outputs_dental_hqsam`)
Visual inspection of the test crops proved that DentalMedSAM-HQ was **inferior** to the previous YOLO + MedSAM baseline:
- **Severe Gum Bleed**: Images like `8764_tooth_crop.png` and `7018_tooth_crop.png` included the entire upper maxillary gingiva as a solid pink band across the teeth.
- **Eaten Margins**: Images like `IMG_2385_tooth_crop.png` and `7625_tooth_crop.png` had ragged bite marks, vertical stripe gaps, and noisy lateral slivers.

### Conclusion & Archival to `trailnerror/`
- DentalMedSAM-HQ was abandoned in favor of the cleaner, more reliable YOLO + standard MedSAM pipeline.
- The experiment code was moved and renamed to `trailnerror/`:
  - `module_2_medsam_finetune/train_hq.py` → `trailnerror/module2_train_hq.py`
  - `module_3_medsam_inference/infer_hq.py` → `trailnerror/module3_infer_hq.py`
- `module_5_integration/pipeline.py` was restored to use the original YOLO + MedSAM inference cleanly.
