# Used for a touch/Apple Pencil-reliable alternative to the drag-based box
# tool above - streamlit-drawable-canvas (fabric.js) has no documented
# touch support and genuinely doesn't work with touch/pencil drag gestures
# in practice (confirmed - touch-action CSS and a smaller canvas size both
# failed to fix it). This library's default mode binds to a plain `onclick`
# handler (confirmed by reading its frontend source), which browsers
# reliably synthesize from a tap on any touchscreen - fundamentally
# different and more reliable than canvas drag. Used in a two-tap
# (not drag) mode for exactly that reason - see app.py's box_prompt stage.
